# V1.3.7 学院安全评分与错误选项可见性修复版

基于 V1.3.6 继续叠加，不新开学院分支。

## 修复点

1. 课后考核完整完成后才进入 SUS 的门控继续保留。
2. 学院模式下，若学习者选择“继续观察/暂不改变输入”等不恰当选项，即使随后补全所有正确动作，也不再显示 100/100。
3. 学院模式新增安全扣分字段：`academy_safety_penalty_points`。
4. 报告中新增 `academy_harmful_actions` 与 `academy_harmful_action_selected`。
5. 已完成“暂停可疑药物/液体”后，不再显示“继续观察，暂不改变当前输入”这一已失去场景意义的错误按钮。
6. 已完成直接呼救后，不再显示“让家属去找人”等不合时宜的呼救错误选项。
7. 临床模式未改动。

## 说明

V1.3.6 中发现：课后考核若完整走完核心节点，即可进入 SUS，这一点符合预期；但中途若点击错误选项，系统仍可给满分。本版修复该评分逻辑。
