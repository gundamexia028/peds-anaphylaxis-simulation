# V1.3.6 学院课后考核完成门控修复版

## 修复原因

V1.3.5 中，学院课后考核病例在早期发生低血压/低氧恶化时，可能被判定为 `failure` 并触发阶段结束；由于课后考核结束后统一接入 SUS/教学体验问卷，导致学习者尚未完成完整课后考核流程即跳转至 SUS。

## 修复内容

1. 学院初始病例与变体病例的失败终止条件放宽：早期低血压或低氧恶化仅作为风险/病情进展记录，不再直接终止阶段。
2. 学院病例成功终止条件收紧：必须完成识别、暂停可疑输入、呼救、ABC支持与监测、抢救物品/肾上腺素准备与核对配合、复评、家属沟通、SBAR汇报后，才判定为完整完成。
3. SUS/教学体验问卷增加完成门控：仅当学院模式 + 课后考核 + 完整成功完成核心路径时开放。
4. 学院考试模式禁用“我已确认完成抢救”提前结束按钮，防止误触造成提前终止。
5. 临床模式未改动。

## 版本线

V1.3.4 → V1.3.5 → V1.3.6，未另开学院模式版本线。
