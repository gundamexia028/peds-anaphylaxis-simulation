# V1.3.1 双模式 + 正式采集质控锁定版更新说明

## 一、为什么从 V1.2.11 重新合并

经对比，早期 V1.3.0 已实现“临床模式/学院模式”的基本框架，但其底座早于 V1.2.10/V1.2.11，未完整包含以下正式采集功能：

- 正式采集 / 测试演练区分；
- 工作年限核对；
- 现场备注 / 异常记录；
- 一人一行配对分析 CSV；
- 数据质控提示 CSV；
- 三阶段完整且无重复才标记 `formal_analysis_ready`；
- 基线阶段任意结局均触发补充问卷；
- 肾上腺素分项评分与有效完成时间线；
- 糖皮质激素按剂量和时机共同判定有效。

因此，V1.3.1 采用“以 V1.2.11 为底座，回灌双模式功能”的方式完成，避免正式采集质控功能回退。

## 二、双模式设计

### 1. 临床模式

适用对象：临床护士、低年资护士、科室培训对象。

保留原有流程：

- 基线评估：考试模式 + 初始病例；
- 模拟培训：训练模式 + 初始病例；
- 培训后考核：考试模式 + 变体病例 Variant A。

保留原有临床能力要求：

- 停止可疑药物/输液；
- 呼救；
- ABC评估；
- 高流量给氧；
- 体位管理；
- 监护与血压评估；
- 肌注肾上腺素剂量核对；
- 快速补液容量核对；
- 两次复评；
- 支气管舒张剂、糖皮质激素；
- 家属沟通；
- SBAR交班；
- 条件性高级支持/CPR/球囊面罩分支。

### 2. 学院模式

适用对象：高职/大专护生、本科护生、实习前护生、见习护生。

流程设置：

- 课前测评：考试模式 + 学院基础病例；
- 模拟训练：训练模式 + 学院基础病例；
- 课后考核：考试模式 + 学院变体病例。

训练目标：

- 识别疑似药物过敏反应与危险信号；
- 停止可疑药物/输液并保留通路；
- 呼叫老师、上级护士或医生；
- 基础给氧支持；
- 连接监护；
- 测量血压与评估循环状态；
- 准备抢救车/急救药物并配合核对；
- 完成基础复评；
- 进行基础家属安抚；
- 完成简化 SBAR 汇报。

学院模式不要求护生独立完成肾上腺素给药、快速补液或高级生命支持。

## 三、学院模式评分结构

|---|---:|---|

总分 100 分。

## 四、数据字段更新

新增或强化字段包括：

- `system_mode`：clinical / academy；
- `system_mode_label`：临床模式 / 学院模式；
- `participant_type`：clinical_nurse / nursing_student；
- `school_name`、`student_level`、`student_grade`、`student_class`；
- `workflow_script_role`：initial / variant / academy_initial / academy_variant；
- `collection_mode`：正式采集 / 测试演练。
