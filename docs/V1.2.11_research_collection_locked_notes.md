# V1.2.11 正式采集质控锁定版更新说明

本版基于 V1.2.10 研究采集修订版继续修正，定位为正式研究采集前的质控锁定版本。

## 一、核心修正

1. **正式主分析纳入口径收紧**
   - `formal_analysis_ready` 由“正式采集 + 基线/培训后配对”调整为：
     - 采集模式为“正式采集”；
     - 基线评估、模拟培训、培训后考核三阶段均有记录；
     - 三阶段均无重复记录。
   - 仅有基线评估与培训后考核配对，但缺少中间模拟培训者，不再标记为可纳入正式主分析。

2. **基线评估后补充问卷触发条件修正**
   - 基线评估无论以何种方式结束，均进入“既往经历补充问卷”。
   - 覆盖：标准完成、超时、失败、死亡分支、危重转PICU、受试者主动确认完成等。
   - 目的：避免基线失败或超时记录缺失“既往过敏反应培训/仿真培训/真实处置经历”等重要协变量。

3. **现场备注/异常记录清空机制**
   - 每一阶段保存并回跳登记界面后，自动清空 `collection_note`。
   - 避免上一阶段或上一名受试者的备注遗留到下一条记录。

4. **清洁打包**
   - 删除 `__pycache__`、`.Rhistory`、运行日志等不应进入正式部署包的文件。
   - 根目录统一为 `peds_web_v1_2_11_research_collection_locked`。

## 二、保留的 V1.2.10 重要改进

- 保留“正式采集/测试演练”采集模式；
- 保留工作年限核对；
- 保留现场备注/异常记录；
- 保留管理员后台导出：汇总CSV、操作明细CSV、完整JSONL、一人一行配对分析CSV、质控提示CSV；
- 保留肾上腺素分项评分、有效完成时间线、有效关键步骤统计；
- 保留糖皮质激素按剂量和时机共同判定有效；
- 保留肾上腺素剂量不足不产生一线治疗改善的逻辑。

## 三、推荐正式采集口径

正式研究主分析建议仅纳入：

- 采集模式 = 正式采集；
- 基线评估、模拟培训、培训后考核三阶段完整；
- 无重复阶段记录，或重复记录已由管理员人工确认并剔除；
- 无现场重大干预、断网、误选采集模式等影响数据有效性的异常。

V1.2.8 及 V1.2.10 以前的试运行数据建议保留为预试运行和系统优化依据，不纳入正式主分析。
