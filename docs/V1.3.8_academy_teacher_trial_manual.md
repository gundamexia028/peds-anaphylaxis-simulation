# V1.3.8 学院教师试用说明书

## 一、系统定位

本系统为“儿童药物诱发严重过敏反应/过敏性休克抢救”动态分支虚拟仿真教学系统。V1.3.8 为学院教师封闭预试运行版，主要用于请学院护理教师从教学角度评价系统的适配性、可用性、难度和流程设计。

## 二、适用对象

当前试用对象为学院护理教师、护理教育专家和少量临床护理专家。暂不建议大规模发给学生正式使用。

## 三、试用目标

1. 评价病例是否适合在校护生学习。
2. 评价护生角色定位是否清楚。
3. 评价选项是否清晰、是否存在泄题。
4. 评价动态分支是否符合教学逻辑。
5. 评价评分结果是否符合教师对学生能力的判断。
6. 发现界面、流程、文字和后台导出问题。

## 四、学院模式能力重点

学院模式不考查护生独立完成临床抢救的能力，而是考查：早期识别、及时呼救、暂停可疑药物/液体、保留静脉通道、基础氧疗与监测、准备抢救物品、配合老师/医生核对急救用药、复评、家属沟通和 SBAR 汇报。

## 五、推荐试用流程

1. 进入学院模式。
2. 完成身份与基础信息登记。
3. 完成课前测评。
4. 完成基线补充问卷。
5. 进入模拟训练，观察提示反馈是否适合教学。
6. 完成课后考核，注意系统是否完整走完流程后再进入 SUS。
7. 完成 SUS 与教学体验问卷。
8. 查看个人结果报告。
9. 管理者后台查看学院数据导出是否正常。

## 六、教师重点观察问题

- 病例是否真实、适合护生。
- 操作按钮是否能完整显示。
- 文字是否能看懂，有无过度专业或过度提示。
- 错误选项后的病情变化是否合理。
- 课后考核是否会提前跳转。
- 点错关键操作后是否仍然满分。
- 结果报告是否便于教师判断学生薄弱环节。
- 后台数据是否能区分学院和临床。

## 七、反馈建议

请教师试用后重点反馈：最需要修改的选项、最不符合教学实际的流程、是否适合课堂使用、是否适合护生自主训练、是否建议进入小样本护生可用性测试。

## 八、数据使用提醒

V1.3.8 阶段产生的数据建议标记为教师预试运行数据，不纳入正式研究效果评价。正式学生数据采集应在教师反馈修订完成后再开始。
