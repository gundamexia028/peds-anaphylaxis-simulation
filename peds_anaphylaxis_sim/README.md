# 儿科药物诱发严重过敏反应动态分支模拟引擎｜V1.2.11

本目录包含动态分支仿真核心引擎、病例脚本和评分逻辑。

## 核心文件

- `engine.py`：仿真状态、动态病情演化、评分、完成条件、报告生成；
- `scenarios/peds_ward_anaphylaxis_iv_initial.json`：基线评估/模拟培训初始病例；
- `scenarios/peds_ward_anaphylaxis_iv_variantA.json`：培训后考核变体病例。
