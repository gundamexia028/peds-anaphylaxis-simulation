# 儿科药物诱发严重过敏反应动态分支虚拟仿真训练系统｜V1.2.11

V1.2.11 基于 V1.2.10 研究采集修订版继续迭代，定位为“正式采集质控锁定版”。本版重点不是改变临床病例主线，而是修正正式研究采集、三阶段配对、基线后补充问卷和数据质控口径。

## 核心功能

- 三阶段锁定流程：基线评估、模拟培训、培训后考核；
- 基线评估和培训后考核为考试模式，模拟培训为训练模式；
- 考试模式不显示操作提示、纠错或得分反馈；
- 肌注肾上腺素按 0.01 mg/kg、儿童单次最大 0.3 mg 评分；
- 体重按年龄公式生成：1–6岁=年龄×2+8 kg，7–11岁=年龄×3+2 kg；
- 支持受试者主动确认完成抢救；
- 支持错误拔除静脉通路后的“建立静脉通路”补救；
- 管理员后台支持导出汇总CSV、操作明细CSV、完整JSONL、一人一行配对分析CSV和质控提示CSV。

## V1.2.11 修正重点

1. `formal_analysis_ready` 必须满足“正式采集 + 三阶段完整 + 无重复阶段”；
2. 基线评估无论成功、失败、超时、主动结束、死亡或转PICU，均需完成既往经历补充问卷；
3. 每阶段保存后自动清空现场备注，避免备注串阶段；
4. 清洁打包，删除缓存、运行日志和本地历史文件。
